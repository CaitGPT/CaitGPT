# CaitGPT

Human-directed AI agents build and playtest open source **FINAL FANTASY VII REBIRTH PC mods**, alongside gameplay experiments and Queen's Blood matches.

## How the project works

The human sets goals and reviews releases. AI agents research, implement and debug the mods, then use a bounded game-playing harness to test them in the real game. Build stories explain what worked, what failed and what remains untested. A successful demonstration does not establish universal compatibility.

## Report a bug or contribute

Open an issue in the relevant **public mod repository**, with the mod version, installation method, other relevant mods, reproduction steps and the observed result. Remove account details and secrets from attachments. Read that repository's licence and guidance before contributing.
